WaitPlay Privacy Policy

Last updated: September 1, 2026

WaitPlay is a browser extension that turns long waiting periods on webpages into short mini-games. This policy explains what information WaitPlay accesses, what it stores locally, and how its optional Internet Sharing feature works.

1. Information used by WaitPlay

WaitPlay monitors active network requests in the browser to determine whether a webpage has been waiting for an extended period. This information is used only to decide when to offer a mini-game and, when enabled by the user, when to stop the game after the relevant request finishes or fails.

WaitPlay does not build or store a browsing-history database. It does not intentionally collect or store passwords, authentication information, payment information, health information, personal communications, or the contents of webpages.

2. Information stored locally

WaitPlay stores extension settings and game-related information in the browser's local extension storage. This may include the selected game, favorite games, high scores, language preference, appearance preference, automatic-play settings, and Internet Sharing preference.

This information is used to provide the extension's features and preserve the user's preferences between browser sessions. WaitPlay does not require a user account.

3. Optional Internet Sharing

WaitPlay includes an optional Internet Sharing feature provided through Mellowtel. The feature is disabled by default. It does not start unless the user explicitly enables it and accepts the consent notice shown by WaitPlay.

When Internet Sharing is enabled, Mellowtel uses a portion of the user's unused network bandwidth and computing resources to access publicly available web data on behalf of third-party clients. According to Mellowtel's current privacy policy and terms, Mellowtel does not collect, share, or sell personal data from end users, and its service is designed not to use the user's personal browsing history, cookies, or user-specific activity.

Mellowtel may process limited technical information needed to operate and protect its service, including anonymized information related to network activity. Mellowtel's own processing is governed by its Privacy Policy and Terms of Service.

Users can disable Internet Sharing at any time from the WaitPlay settings. Turning the feature off stops WaitPlay from using the Mellowtel sharing functionality.

4. Third-party services

The optional Internet Sharing feature is provided by Mellowtel. WaitPlay does not sell user data or use user data for advertising profiles, creditworthiness decisions, or lending purposes.

5. Data security

WaitPlay is designed to minimize data collection. Extension preferences and game information are stored using browser-provided extension storage. WaitPlay does not intentionally store sensitive personal information.

6. User control

Users can disable automatic game launching, automatic game ending, and Internet Sharing from the extension settings. Users can also remove the extension at any time through the browser's extension management page.

7. Changes to this policy

This policy may be updated when WaitPlay's functionality or its use of third-party services changes. The latest version will be published at this URL.

8. Contact

For privacy questions or requests concerning WaitPlay, please use the support contact provided on the WaitPlay extension's store listing.
